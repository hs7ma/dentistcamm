# تعليمات إنشاء جدول إعدادات المناخ

## الخطوات:

### 1️⃣ افتح Supabase Dashboard
1. اذهب إلى [supabase.com](https://supabase.com)
2. سجل دخول لحسابك
3. افتح مشروعك

### 2️⃣ افتح SQL Editor
1. من القائمة الجانبية، اضغط على **SQL Editor**
2. اضغط على **+ New query**

### 3️⃣ نفذ السكريبت
1. افتح ملف `database/05_climate_settings.sql`
2. انسخ كل المحتوى
3. الصقه في SQL Editor
4. اضغط **Run** أو **Ctrl+Enter**

### 4️⃣ تحقق من النجاح
يجب أن ترى رسالة نجاح وسجل واحد:
```
Successfully ran 1 query
```

### 5️⃣ تحقق من الجدول
1. اذهب إلى **Table Editor**
2. يجب أن ترى جدول جديد: `climate_settings`
3. يحتوي على سجل واحد بالقيم الافتراضية

---

## ما يفعله السكريبت:

✅ ينشئ جدول `climate_settings`  
✅ يضيف أعمدة لكل الإعدادات (الحرارة، الرطوبة، الهوامش)  
✅ يدرج سجل افتراضي  
✅ يضيف trigger لتحديث `updated_at` تلقائياً  
✅ يفعل Row Level Security (RLS)  

---

## بعد التنفيذ:

✅ أعد تشغيل السيرفر: `npm start`  
✅ الإعدادات ستُحفظ في Supabase تلقائياً  
✅ ستعمل حتى على الاستضافة السحابية  

---

## ملاحظات:

- الجدول يحفظ سجل واحد فقط (`setting_key = 'default'`)
- عند الحفظ، يُحدّث السجل الموجود بدلاً من إضافة سجل جديد (UPSERT)
- الإعدادات تُحفظ أيضاً في ملف محلي `setpoint_config.json` للتطوير المحلي
