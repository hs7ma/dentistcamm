# دليل نظام المضخة المركزية 🚰

## نظرة عامة

النظام يتكون من **مضخة واحدة مركزية** تخدم **8 أحواض**، بدلاً من 8 مضخات منفصلة.

```
                    ┌─────────────────┐
                    │  المضخة المركزية │
                    │   (على ESP32-04) │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
    ┌────┴────┐        ┌────┴────┐        ┌────┴────┐
    │ صمام 1  │        │ صمام 4  │        │ صمام 8  │
    │ ESP32-01│        │ ESP32-04│        │ ESP32-08│
    └─────────┘        └─────────┘        └─────────┘
```

## ⚡ طريقة العمل

### عند طلب الري من أي حوض:

1. **الوحدة** (مثلاً plant-bed-02) تطلب الري
2. **تفتح صمامها** المحلي
3. **ترسل طلب** للخادم لتشغيل المضخة المركزية
4. **الخادم** يضيف الوحدة لقائمة الطالبين
5. **plant-bed-04** تستعلم من الخادم "هل يجب تشغيل المضخة؟"
6. **إذا نعم** → تشغيل المضخة المركزية

### عند انتهاء الري:

1. **الوحدة** تغلق صمامها
2. **ترسل إلغاء** لطلب المضخة
3. **الخادم** يحذف الوحدة من قائمة الطالبين
4. **إذا القائمة فارغة** → plant-bed-04 توقف المضخة

## 📝 خطوات الإعداد

### 1. تحديث إعدادات Wi-Fi والخادم

في كلا ملفي الـ firmware، عدّل:

```cpp
// Wi-Fi
constexpr char WIFI_SSID[] = "اسم_الشبكة";
constexpr char WIFI_PASSWORD[] = "كلمة_المرور";

// API - عنوان الخادم
constexpr char API_BASE_URL[] = "http://192.168.1.XXX:3000";
```

### 2. رفع الـ Firmware

#### للوحدة الرابعة (plant-bed-04):
```bash
# استخدم esp32_central_pump_unit.ino
# تأكد أن UNIT_ID = "plant-bed-04"
```

#### لباقي الوحدات السبع:
```bash
# استخدم esp32_valve_only_unit.ino
# غيّر UNIT_ID لكل وحدة:
# "plant-bed-01", "plant-bed-02", "plant-bed-03", 
# "plant-bed-05", "plant-bed-06", "plant-bed-07", "plant-bed-08"
```

### 3. التحقق من الاتصال

بعد تشغيل الوحدات، تحقق من:
- اتصال جميع الوحدات بالـ Wi-Fi
- ظهور جميع الوحدات في صفحة الري على الويب
- استجابة المضخة المركزية لطلبات الري

## 🔧 API الجديد للمضخة المركزية

### GET /api/central-pump
الحصول على حالة المضخة المركزية

```json
{
  "ok": true,
  "centralPump": {
    "active": true,
    "requestingUnits": ["plant-bed-01", "plant-bed-03"],
    "controlledBy": "plant-bed-01",
    "pumpUnitId": "plant-bed-04"
  }
}
```

### POST /api/central-pump/request
طلب تشغيل المضخة (من ESP32)

```json
{ "unitId": "plant-bed-01" }
```

### POST /api/central-pump/release
إلغاء طلب المضخة (من ESP32)

```json
{ "unitId": "plant-bed-01" }
```

### GET /api/central-pump/should-run
للوحدة الرابعة: هل يجب تشغيل المضخة؟

```json
{
  "ok": true,
  "shouldRun": true,
  "requestingUnits": ["plant-bed-01", "plant-bed-03"]
}
```

## ⚠️ ملاحظات مهمة

1. **إذا انقطع اتصال plant-bed-04**: المضخة ستتوقف، ولن يعمل الري لأي حوض
2. **الري المتزامن**: يمكن لعدة أحواض الري في نفس الوقت (المضخة تعمل ما دام هناك طلب واحد على الأقل)
3. **الأمان**: عند فقدان الاتصال، يتم إغلاق الصمامات وإلغاء طلبات المضخة

## 🐛 استكشاف الأخطاء

### المضخة لا تعمل:
1. تحقق من اتصال plant-bed-04 بالخادم
2. تحقق من أن الصمام مفتوح على الأقل في وحدة واحدة
3. راجع Serial Monitor لـ plant-bed-04

### الري لا يعمل على حوض معين:
1. تحقق من اتصال الوحدة بالخادم
2. تحقق من فتح/إغلاق الصمام
3. تحقق من إرسال طلب المضخة

### المضخة لا تتوقف:
1. تحقق من أن جميع الوحدات أرسلت إلغاء الطلب
2. راجع `/api/central-pump` لمعرفة الوحدات الطالبة
