# 🔧 دليل إعداد المضخة المركزية

## 📋 ملخص التكوين الجديد

تم تعديل النظام لدعم **مضخة واحدة مركزية** لجميع الأحواض الـ 8 بدلاً من 8 مضخات منفصلة.

### التكوين الحالي:

| المكون | الموقع |
|--------|--------|
| **المضخة المركزية** | متصلة على ESP32 الخاص بـ `plant-bed-04` |
| ESP32 للوحدات 1,2,3,5,6,7,8 | صمام + حساسات فقط (بدون مضخة محلية) |
| ESP32 للوحدة 4 | المضخة المركزية + صمام + حساسات |

---

## 📁 ملفات الـ Firmware

### 1. للوحدات بدون مضخة (7 وحدات)
استخدم الملف: **`esp32_plant_bed_no_pump.ino`**

```
الوحدات: plant-bed-01, plant-bed-02, plant-bed-03, plant-bed-05, plant-bed-06, plant-bed-07, plant-bed-08
```

**قبل الرفع:** غيّر `UNIT_ID` في بداية الكود:
```cpp
constexpr char UNIT_ID[] = "plant-bed-01";  // غيّر لكل وحدة
```

### 2. للوحدة الرابعة (المضخة المركزية)
استخدم الملف: **`esp32_plant_bed_central_pump.ino`**

```
الوحدة: plant-bed-04 فقط
```

**⚠️ لا تغير UNIT_ID في هذا الملف!**

## 🔌 توصيل GPIO

| GPIO | الوظيفة |
|------|---------|

| GPIO | الوظيفة |
|------|---------|
| GPIO 34 | حساس رطوبة التربة (Analog) |
| GPIO 35 | حساس رطوبة التربة (Digital) |
| GPIO 5 | حساس التدفق |
| **GPIO 18** | **ريلي المضخة المركزية** ⭐ |
| GPIO 19 | ريلي فتح الصمام |

## 🔄 كيف يعمل النظام

### عند طلب الري من أي حوض:

1. **الوحدة (مثلاً plant-bed-01)** تفتح الصمام الخاص بها
2. **ترسل طلب للخادم** لتشغيل المضخة المركزية
3. **الخادم** يسجل الطلب ويُخبر الوحدة الرابعة
4. **الوحدة الرابعة** تشغّل المضخة المركزية
5. **الماء يتدفق** عبر الصمام المفتوح للحوض المطلوب

### عند انتهاء الري:

1. **الوحدة** تُغلق الصمام
2. **ترسل إلغاء الطلب** للخادم
3. **إذا لم تبقَ وحدات تطلب المضخة** → الوحدة الرابعة تُوقف المضخة

### الري المتزامن:

يمكن لأكثر من حوض أن يري في نفس الوقت! المضخة تعمل طالما هناك وحدة واحدة على الأقل تطلبها.

## ⚙️ إعدادات Wi-Fi والخادم

في كل ملف firmware، عدّل هذه الإعدادات:

```cpp
// Wi-Fi
constexpr char WIFI_SSID[] = "اسم_الشبكة";
constexpr char WIFI_PASSWORD[] = "كلمة_المرور";

// API - عنوان الخادم
constexpr char API_BASE_URL[] = "http://192.168.1.XXX:3000";
```

**للحصول على IP الخادم:**
- Windows: `ipconfig`
- Mac/Linux: `ifconfig` أو `ip addr`

## 🔧 استكشاف الأخطاء

### المضخة لا تعمل:
- تأكد أن الوحدة الرابعة متصلة ومتصلة بالخادم
- تحقق من سجل Serial للوحدة الرابعة

### الصمام يفتح لكن لا يوجد ماء:
- تأكد أن المضخة المركزية تعمل (انظر بطاقة المضخة في الواجهة)
- تحقق من توصيل المضخة على GPIO 18 في الوحدة الرابعة

### وحدة لا تظهر في القائمة:
- تأكد من إرسال بيانات الحساس للخادم (انظر سجل Serial)
- تحقق من UNIT_ID في الكود

## 📊 APIs الجديدة

### GET /api/central-pump
الحصول على حالة المضخة المركزية

### POST /api/central-pump/request
طلب تشغيل المضخة (يُستخدم من ESP32)
```json
{ "unitId": "plant-bed-01" }
```

### POST /api/central-pump/release
إلغاء طلب المضخة (يُستخدم من ESP32)
```json
{ "unitId": "plant-bed-01" }
```
