# وحدة الأحواض الزراعية - Plant Bed Unit

## 📋 نظرة عامة

وحدة الأحواض الزراعية هي نظام متكامل للتحكم في الري باستخدام ESP32. تدعم الوحدة أنظمة ري متعددة: كمي، وقتي، وحسب رطوبة التربة، بالإضافة للتحكم اليدوي.

## 🔧 المكونات المطلوبة

### المكونات المادية:
- ESP32 Development Board
- حساس رطوبة التربة (Soil Moisture Sensor) - يعمل على 3.3V/5V
- حساس تدفق الماء (Water Flow Sensor) - يعمل على 12V
- 4 ريلايهات (4-Channel Relay Module) - تعمل على 12V
- شاشة OLED SSD1306 (128x64) أو LCD I2C
- مضخة ماء (12V)
- قفل/صمام كهربائي (12V) - 3 رؤوس (مشترك، فتح، إغلاق)
- مصدر طاقة 12V
- أسلاك توصيل

### المكتبات المطلوبة (Arduino IDE):
- WiFi.h (مدمجة)
- HTTPClient.h (مدمجة)
- ArduinoJson.h (تثبيت من Library Manager)
- Wire.h (مدمجة)
- Adafruit_SSD1306.h (تثبيت من Library Manager)
- Adafruit_GFX.h (تثبيت تلقائي مع SSD1306)

## 📌 التوصيلات

### GPIO Pin Assignments:
```
ESP32 Pin    المكون
─────────────────────────────────────
GPIO 4   → حساس رطوبة التربة (Analog)
GPIO 5   → حساس تدفق الماء (Digital Interrupt)
GPIO 16  → SDA (I2C للشاشة)
GPIO 17  → SCL (I2C للشاشة)
GPIO 18  → ريلي المضخة (12V)
GPIO 19  → ريلي فتح القفل (12V)
GPIO 21  → ريلي إغلاق القفل (12V)
GPIO 22  → ريلي حساس التدفق (12V - NC)
```

### توصيلات الريلايهات:
- **ريلي 1 (GPIO 18)**: COM → 12V+, NO → المضخة (+)
- **ريلي 2 (GPIO 19)**: COM → 12V+ (مشترك القفل), NO → قفل الفتح (+)
- **ريلي 3 (GPIO 21)**: COM → 12V+ (مشترك القفل), NO → قفل الإغلاق (+)
- **ريلي 4 (GPIO 22)**: COM → 12V+, NC → حساس التدفق (+) (Normally Closed)

## ⚙️ الإعداد

### 1. تحديث الإعدادات في الكود:

افتح ملف `esp32_plant_bed_unit.ino` وحدّث:

```cpp
// Wi-Fi
constexpr char WIFI_SSID[] = "اسم_الشبكة";
constexpr char WIFI_PASSWORD[] = "كلمة_المرور";

// API
constexpr char API_BASE_URL[] = "http://192.168.1.50:3000";
constexpr char UNIT_ID[] = "plant-bed-01";

// معايرة حساس التدفق (حسب نوع الحساس)
constexpr float PULSES_PER_LITER = 450.0; // YF-S201: 450 نبضة/لتر
```

### 2. معايرة حساس رطوبة التربة:

قد تحتاج لتعديل القيم التالية حسب نوع الحساس:
```cpp
constexpr uint16_t SOIL_MOISTURE_MIN = 0;   // أقل قيمة (هواء جاف)
constexpr uint16_t SOIL_MOISTURE_MAX = 4095; // أعلى قيمة (ماء)
```

### 3. رفع الكود:

1. افتح Arduino IDE
2. اختر Board: ESP32 Dev Module
3. حدّث المكتبات المطلوبة
4. ارفع الكود إلى ESP32

## 🎮 أنظمة الري

### 1. الري الكمي:
- ري بكمية محددة من الماء (باللتر)
- المستخدم يحدد الكمية من الواجهة
- النظام يفتح القفل، يشغل المضخة، ويراقب التدفق حتى الوصول للكمية المطلوبة

### 2. الري الوقتي:
- ري لمدة زمنية محددة (بالدقائق)
- المستخدم يحدد المدة من الواجهة
- النظام يفتح القفل، يشغل المضخة، وينتظر المدة المحددة

### 3. الري حسب الرطوبة:
- ري تلقائي عند انخفاض رطوبة التربة تحت عتبة معينة
- المستخدم يحدد:
  - عتبة الرطوبة (%)
  - نوع الري (كمي أو وقتي)
  - قيمة الري (لتر أو دقيقة)

### 4. التحكم اليدوي:
- تحكم فوري من الواجهة
- يمكن تشغيل/إيقاف المضخة
- يمكن فتح/إغلاق القفل

## 🐛 استكشاف الأخطاء

### الوحدة لا تتصل بالخادم:
- تحقق من إعدادات Wi-Fi
- تحقق من عنوان API_BASE_URL
- تأكد من تشغيل الخادم

### حساس التدفق لا يعمل:
- تحقق من توصيل ريلي 4 (يجب أن يكون مغلقاً لتفعيل الحساس)
- تحقق من معايرة PULSES_PER_LITER
- تحقق من توصيل Signal إلى GPIO 5

### حساس الرطوبة يعطي قراءات خاطئة:
- قم بمعايرة SOIL_MOISTURE_MIN و SOIL_MOISTURE_MAX
- تأكد من توصيل الحساس بشكل صحيح
- تحقق من جودة الحساس
